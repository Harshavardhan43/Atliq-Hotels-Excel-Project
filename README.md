# Atliq Hotels - Booking Performance Analysis

## Overview
Analyzed hotel booking performance for Atliq Hotels chain to find why revenue is leaking despite high bookings.

## Dataset
- Period: May to July 2022
- Total Bookings: 1,34,590
- Hotels: 25 properties
- Cities: Delhi, Mumbai, Hyderabad, Bangalore
- Room Types: Standard, Elite, Premium, Presidential

## Key Metrics
- Total Revenue Generated: 1,70,87,71,229
- Occupancy Booked: 57.87%
- Occupancy Realised: 40.59%
- Cancellation Rate: 24.83%
- No Show Rate: 5.02%
- ADR: 12,696
- RevPAR: 7,347
- Revenue Leakage: 29.87 Cr

## Key Insights
1. High cancellation is the main reason for revenue leakage
2. Weekend Occupancy 73.5% vs Weekday 51.3% - Weekend demand is high
3. Mumbai has highest RevPAR, Hyderabad has lowest
4. Top leakage properties: Atliq Exotica Mumbai, Atliq Palace Mumbai
